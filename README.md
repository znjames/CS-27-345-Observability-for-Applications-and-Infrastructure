## Problem

Applications can have numerous services with their own metrics, logs, and alerts. This project attempts to centralize this information and generate alerts before incidents even occur.

Windows
---
1. Start up Docker Desktop
2. Copy `.env.example` and rename to `.env` on local computer
3. Run `docker compose up`
4. Visit `localhost:8080` in your browser

Linux
---
1. Copy `.env.example` and rename to `.env` on local computer
2. Run `docker compose up`
3. Visit `localhost:8080` in your browser
