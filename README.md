## Problem

Applications can have numerous services with their own metrics, logs, and alerts. This project attempts to centralize this information and generate alerts before incidents even occur.

## Setup

1. run `python3 -m venv venv` to create a virtual environment
2. run `python3 auth/auth.py` to start the python authentication server
3. open `bank.html` using Microsoft Live Preview or your browser

This will likely be replaced with a setup script or Docker Compose as the enviroment becomes more complicated.
